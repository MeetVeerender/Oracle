Oracle RAC Notes:

Cardinality is number of ASM instances in a cluster.

Private network alias Interconnect is used to communicate between cluster nodes.

Cache Fusion is a diskless feature that provides block data to requesting memory cache instance from holding node memory cache.

Global Processes helps maintains cache coherency in case of node failures.

RAC Tools:
Cluster verification utility
OEM
SVC

Performance Tuning:

Latch

Public Network: Each node has a network connection called Public network. This network provides the connection applications that use the database or clustered applications.
Private network: Also called as Interconnect provides the connection between nodes of a cluster. Shared storage must be accessible from each node.
