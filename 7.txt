Workaround Monitoring for Oracle8i Databases

On occasion we have run into an issue with OEM monitoring of Oracle8i databases.  It normally works, but at times it has failed to report problems.  As such, we have implemented some failsafe monitoring.  There are a few scripts on pldbawb2 to provide some workaround monitoring as listed below.  These scripts run on cron and monitor the following:

1)	Availability 
(chk_remote_db_up.sh)
2)	Objects being able to extend (contiguous space for next extent, and maxextents) 
(chk_remote_objects_extend.sh)
3)	Free space in all tablespaces 
(chk_remote_tbs_space.sh)

These scripts run on cron, log into the remote databases, and if a problem is detected they sent an email to pagedba@avaya.com.
